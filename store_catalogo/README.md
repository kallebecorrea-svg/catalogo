# SenaiBUM Store

Projeto de catálogo de produtos desenvolvido em React com Vite, com foco em uma loja de tecnologia.

## Sobre o projeto

Este projeto foi criado para apresentar uma vitrine de produtos como:
- periféricos
- monitores
- áudio
- promoções

A aplicação mostra cards com nome, imagem, categoria e preço, além de destacar produtos em promoção.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS

## Autor

Projeto desenvolvido por Kallebe Avozani um estudante do Senai, do curso de Análise e Desenvolvimento de Sistemas.

## Como executar

1. Instale as dependências:
   npm install

2. Inicie o projeto:
   npm run dev

3. Abra no navegador a URL indicada pelo Vite.

## Objetivo

Praticar a criação de interfaces modernas, organização de componentes e estilização de uma loja virtual.
